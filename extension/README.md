# 看山浏览器插件 v0.9.0

## 安装

1. 启动看山桌宠，点击桌宠打开阅读伙伴网页。
2. Chrome 打开 chrome://extensions，Edge 打开 edge://extensions。
3. 开启开发者模式，选择“加载已解压的扩展程序”，选择本文件所在文件夹。
4. 刷新阅读伙伴网页，插件会自动连接。在“连接设置”看到“插件已连接”后即可打开知乎，无需复制连接码。
5. 如果已经装过旧版，请先停用旧版，再加载本文件夹；也可在原插件卡片点击重新加载，然后刷新知乎页面。

## 阅读

在知乎回答或文章正文选中文字，选择“保存金句”会直接收好，并显示可撤销的小提示。选择“划线批注”或“解释一下”才展开面板，可填写批注、更改关联问题。最新金句会同步到阅读伙伴，普通划线进入摘录列表。

关闭面板或桌宠离线时，本页未完成的笔记会暂存为草稿。点击右下角“山 · 有一笔未完成”恢复。每个页面保留一笔未完成草稿，插件最多保存最近 30 页的草稿。

解释需要桌宠中已经配置可用的模型。解释失败可以重试，已保存的摘录不会重复添加。阅读兴趣学习沿用阅读伙伴中的开关。

## 连接排查

先启动桌宠，再打开插件里的“打开阅读伙伴并自动连接”。网页会自动建立连接，再刷新知乎页面即可。主动断开后自动连接暂停，可在网页“连接设置”中点击“恢复连接”。

连接到本机 http://127.0.0.1:47840/，不需要复制知乎 Cookie，不需要知乎账号密码。知乎搜索和模型服务沿用桌宠中已有配置。

## 数据

保存的笔记在桌宠本机资料中。未保存草稿和自动连接凭证在浏览器扩展本地存储中。卸载扩展会清除扩展草稿；断开连接保留草稿和桌宠笔记。模型解释仅由用户点击发起；若启用了兴趣学习，阅读信号及有限摘录也会按该设置参与分析。

## 验证

通过 29 项项目自动化测试，包含完整桌宠服务下的金句保存与问题关联、连接码验证失败不覆盖原连接、来源限制、离线草稿跨页面重载恢复，以及解释失败后重试不重复保存。界面经过 Electron 渲染检查；实际浏览器安装与线上知乎页面仍需按上述步骤验证。

## v0.8 新增

已配对的插件会保留连接，桌宠恢复运行后，知乎页会自动重试连接；打开阅读伙伴网页时也会自动恢复已有配对。主动断开后不会自动重新配对。初次安装或卸载后，打开阅读伙伴网页即可自动配对。

从“带着问题”中的“去阅读，找线索”打开搜索结果，知乎链接会携带该问题标识。插件默认把金句和批注关联到这个问题，可在批注面板中更改或取消。普通搜索不会沿用之前的问题。问题被删除后不再自动关联。

保存成功后，桌宠轻轻点头并抱书。拖拽、落地和整理书页时会延后反馈，连续保存会合并动作。

## v0.9 自动连接

本机阅读页的内容脚本通过已鉴权的网页会话建立连接，再由插件后台验证并保存凭证。网页与插件之间只交换连接状态，不在页面消息中传递凭证。首次安装、页面尚未就绪和本机服务恢复时均会自动重试；主动断开后保持暂停。网页和弹窗已移除连接码输入。
